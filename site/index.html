把刚才看到的变化说清楚

训练，就是重复这四步

01 / 前向计算

先给出预测

把输入 x 代入 ŷ = w × x + b。ŷ 读作“预测的 y”；w 和 b 是可调整的参数。

02 / 计算损失

把偏差变成一个数

每个预测减去答案，平方后取平均。平方让正负偏差不互相抵消，也让大偏差受到更重惩罚。

03 / 求梯度

判断往哪里调整

梯度描述参数轻微增加时，loss 怎样变化。正梯度提示往减小参数的方向走，负梯度则相反。

04 / 更新参数

沿着下降方向挪一点

新参数 = 旧参数 − 学习率 × 梯度。学习率太大可能跨过低点，反而越走越远。

为什么能从误差算出方向？

以输入 2、答案 5 为例：如果当前预测只有 2，稍微增加 w，就会把预测往 5 推近。梯度把这种局部变化量算出来；多个样本一起决定最终方向。它不需要预先知道正确的 w 和 b。

本例使用三个无噪声样本，是为了看清机制。真实数据往往有噪声，模型也不一定是一条直线；训练集 loss 很低，还需要用未参与训练的数据检查泛化。

从看懂到会做

把同一个过程写进 PyTorch

网页用显式公式演示梯度；下面的程序让 PyTorch 自动求梯度。它在 CPU 上拟合带噪声的直线，并分别记录训练误差和验证误差。

第一次运行

  1. 准备 Python 和 PyTorch，按官方安装页选择自己的系统与 CPU 配置。
  2. 下载 train_linear.py，在文件所在目录运行 python train_linear.py。
  3. 观察 loss 是否下降、w 和 b 是否接近 2 和 1。数据带噪声，所以不要求恰好等于它们。
  4. 将 lr=0.05 改成 lr=0.6 复跑，记录差异。若出现非有限值，程序会停止并提示。

找不到 torch：检查安装依赖和运行脚本是否用了同一个 Python 环境。保留输出中的 Python / PyTorch 版本，方便复现。

prediction = model(x_train)       # 前向：做预测
loss = loss_fn(prediction, y_train) # 衡量误差

optimizer.zero_grad()  # 清掉上一次的梯度
loss.backward()       # 自动求出本次梯度
optimizer.step()      # 根据梯度更新参数
为什么每次先清空梯度？

PyTorch 默认把新算出的梯度累加到参数的 .grad 上。本例每次只想用当前批次的梯度，所以先清空。刻意累积多个小批次梯度也是一种训练方法，但需要相应安排更新时机与损失缩放。
